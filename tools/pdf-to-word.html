About this tool

This converter extracts text from your PDF and packages it as a Word-compatible file. For digital PDFs (born-digital), text and basic paragraph structure are preserved. For scanned/image-only PDFs, run OCR first to get editable text.

How it works

  • Upload a PDF — everything happens in your browser, no upload.
  • We extract text page-by-page using pdf.js (Mozilla's PDF parser).
  • For .docx output, we build a minimal Office Open XML structure with JSZip — opens in Word, Google Docs, LibreOffice.
  • For .html output, we wrap text in semantic HTML with paragraph breaks preserved.

Tips for best results

  • Use digital PDFs (not scans) for best text extraction. For scanned PDFs, try OCR first.
  • Tables, images, and complex layouts are simplified — Word documents are not pixel-perfect copies of PDFs.
  • Need to keep the original layout? Use PDF to Image instead and embed in Word manually.

Frequently asked questions

Will my formatting be preserved?

Paragraphs and basic text formatting (bold, italic) are preserved. Complex layouts (multi-column, headers, footers, tables) are simplified — Word documents are not pixel-perfect copies of PDFs. For exact layout, use PDF to Image.

Can I convert scanned PDFs?

Only if you run OCR first to extract text. Scanned PDFs without OCR are just images, and there is no text to extract. Use our OCR tool to extract text from scans.

What is the file size limit?

There's no enforced limit. Files over ~200MB may run slow on phones or low-RAM devices. Output .docx files are typically much smaller than the input PDF.
