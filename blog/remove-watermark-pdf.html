How to remove a watermark from a PDF
— free, and without uploading it

Some watermarks are a separate layer sitting on top of the page and come off cleanly. Others are baked into the pixels and never will. Here's how to tell the difference, and the fastest way to handle each.

Two kinds of watermark (only one is removable)

Before you try anything, work out which type you're dealing with — it determines whether a clean removal is even possible.

Layered watermarks sit in a separate layer on top of the page, along with the text underneath. These are what "SAMPLE", "DRAFT", and "CONFIDENTIAL" stamps usually are. Because the underlying content is still intact, they can often be removed cleanly.

Flattened watermarks have been merged into the page image or the text itself — common in scanned documents and in exports from design tools. There is no "underneath" left; the pixels are combined. These can only be approximated, never perfectly removed.

How to tell which one you have

Try selecting the text on the page with your mouse. If you can highlight the words around the watermark normally, the content layer is intact and you likely have a layered watermark. If the whole page behaves like one image and you can't select anything, it's flattened — run PDF OCR first if you need the text.

Method 1: Browser-based removal (free, nothing uploaded)

Open the PDF watermark remover, drop the file in, and click Run. It scans for repeated text or image stamps across pages and strips the ones it can identify.

Best for: "SAMPLE" / "DRAFT" stamps, logos tiled across every page, preview watermarks from document platforms.

Everything happens in your browser tab, so a confidential draft never gets uploaded to a stranger's server.

Method 2: Adobe Acrobat Pro (paid)

Acrobat Pro → Edit PDF → Watermark → Remove. It gives you the most control, letting you target specific layers by hand. Costs $22.99/month, and by default files are processed in Adobe's cloud.

Method 3: Print to a new PDF (free, but lossy)

On macOS: open in Preview → Print → Save as PDF, after disabling any print-time watermark options. On Windows: use "Microsoft Print to PDF."

This flattens the file, so it's effective against layered watermarks — but it can also rasterise text, which means you lose searchability and copy. Use it when nothing else works.

When removal won't be clean

"The background is now a solid block of colour"

That means the watermark was a semi-transparent rectangle covering the page. Removing the text leaves the tint behind. Your options: accept the tint, or rebuild the page from the source file.

"Residue where the watermark overlapped text"

Common with flattened watermarks. The pixels merged, so separating them leaves artefacts. Re-exporting from the original document is the only truly clean fix.

"The watermark is inside a scan"

If the watermark was on the physical paper when it was scanned, it's part of the image. No PDF tool can cleanly remove it — you'd need image editing, and results on a full page of text are poor.

A note on doing this legitimately

Remove watermarks only from documents you own or have permission to modify. Watermarks on purchased ebooks, licensed reports, and proof copies exist to enforce a licence — stripping them may breach the terms you agreed to. The legitimate uses are the common ones: cleaning up your own drafts, removing your company's "SAMPLE" stamp from a final version, or preparing a file you have the rights to.

Privacy

Our remover runs entirely in your browser. The file is parsed, cleaned, and re-generated locally — no upload, no server copy, no account. If the document is confidential, that's the only way this should be done.
