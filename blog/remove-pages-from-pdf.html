Why deleting pages is harder than it sounds

PDF isn't a Word document — you can't just "backspace" a page out. Each page is an independent object with its own text, images, annotations, and bookmarks. To remove a page, you have to rebuild the whole file without that page's contents, which requires rewriting the document's internal index. Most "viewers" can't do this; only editors and dedicated tools can.

Method 1: Browser-based, visual page picker (free, no upload)

Open the PDF page remover, drop your file in, and you'll see thumbnails of every page. Click the ones you want to delete, then click Remove. You get a clean PDF back without those pages.

Best for: dropping a cover page, deleting blank pages, removing sensitive pages before sharing, cleaning up scans.

Because it runs in your browser, the file never leaves your device — the kind of tool you want when the pages you're removing are the reason you can't upload.

Method 2: Adobe Acrobat Pro (paid)

Tools → Organize Pages → select the pages → Delete. Acrobat lets you visually drag pages around as well, so you can also reorder, rotate, and insert blank pages from one interface.

Costs $22.99/month, cloud by default.

Method 3: macOS Preview (free, already on your Mac)

Open the PDF in Preview → View → Thumbnails. Hold Cmd and click each page you want to delete, then press Delete on the keyboard.

Works for small jobs; Preview occasionally reorders the file in weird ways when you save, so check the output before sending it anywhere.

Method 4: Microsoft Word (free with Office)

Open the PDF in Word → delete the pages you don't want → File → Save As → PDF.

Big caveat: Word imports PDFs by re-rendering them, which usually degrades the formatting. Embedded fonts get replaced, vector graphics become bitmaps, and bookmarks/links disappear. Only use this for throwaway edits.

Common gotchas

"The bookmarks still point to the deleted pages"

Removing a page doesn't automatically update the document's bookmarks. The PDF is smaller and the content is gone, but clicking an old bookmark may now jump to the wrong page or show an error. For a polished output, also open the bookmark panel and either delete broken bookmarks or repoint them.

"The page numbers in the footer no longer match"

Most PDFs have page numbers baked into the content, not generated dynamically. After deleting a page, the printed numbers in the remaining pages will be off. Tools like Acrobat and browser-based ones can update them; Preview and Word can't.

"Annotations stuck to the deleted pages still show up"

Less common now, but some older PDFs keep annotations as a separate layer that's not always wiped when you delete the page. If your output still shows sticky notes, try the operation in a different tool.

"I deleted the wrong page"

Always check the thumbnails before clicking Remove. Our browser-based tool has an explicit "undo" between actions, and the final file is downloaded as a new copy — your original stays untouched.

What "delete" actually does

No tool truly erases data from a PDF. They all remove the page from the visible structure, but the raw bytes may still be in the file. For most uses that's fine. For highly sensitive documents, also run PDF metadata remover on the output, and consider using Merge PDF to recreate the file from scratch.

Privacy

The pages you're deleting are usually the most sensitive parts of the document — they're why you need to remove them. That's exactly the moment you don't want to upload the file to a stranger's server. Our browser-based remover parses, rebuilds, and outputs the PDF entirely in your browser tab.
