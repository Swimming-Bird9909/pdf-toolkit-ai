— strip the hidden metadata first

Every PDF carries an invisible block of metadata: your name, the software you used, how long you edited, sometimes even where you were. Here's what's in there, and how to remove it before you hit send.

What a PDF quietly stores

Every PDF carries a metadata block that most people never see. Depending on how it was created, it can hold:

  • Author name — usually pulled from your OS account (e.g. zhang.san or Admin)
  • Creating application — "Microsoft® Word 2019", "Google Docs", "Acrobat Pro"
  • Creation and modification timestamps — sometimes down to the second
  • Edit history — how long the file was open, how many times it was saved
  • Device and OS information
  • GPS coordinates — for PDFs generated by some mobile scanner apps
  • Company / template name — the internal name of the template it came from

None of this is visible when you open the document. It only shows up if someone looks.

Why it matters in practice

A few real situations where metadata has caused trouble:

  • A quote sent to a client revealed the internal template name and the author's staff account.
  • A job applicant's CV showed it was last modified at 1:40 a.m. — and originally created from a different company's template.
  • A scanned contract embedded the GPS coordinates of the office where it was scanned.
  • A draft shared externally still carried the redline history the sender thought had been flattened.

None of these are disasters, but all of them are avoidable in about ten seconds.

How to check what's inside

Quickest: open the PDF in a browser, press Ctrl/Cmd + D, and look at the Document Properties panel.

On Windows: right-click the file → Properties → Details tab.

On macOS: open in Preview → Tools → Show Inspector → the Info (ⓘ) tab.

How to strip it (free, no upload)

Open the PDF metadata remover, drop your file, and click Clean. It rewrites the document without the author field, timestamps, software tags, and hidden XMP blocks — then hands you a fresh download.

Because it runs in your browser, the file never leaves your machine. That's the whole point: you're cleaning it because it's sensitive, so uploading it to a random server would defeat the purpose.

Other ways

Acrobat Pro: Tools → Redact → Remove Hidden Information. Powerful, but paid and it uploads by default.

Microsoft Word: File → Info → Check for Issues → Inspect Document → Remove All. Works well for PDFs Word can reopen.

Print to PDF: On macOS, open in Preview and Print → Save as PDF. This usually drops metadata, though it can also rasterise text and disable search.

What metadata removal does NOT do

Be clear about the limits, or you'll get a false sense of security:

  • It will not remove a visible watermark — use the watermark remover for that.
  • It will not delete comments, highlights, or sticky notes.
  • It will not remove "white text on white background" hidden layers.
  • It will not touch text that's already printed on the page — anything visible stays visible.

If you need the page content itself redacted, use a proper redaction tool, not a metadata cleaner.

Make it a habit

The safest workflow is boring: strip metadata on anything leaving your organisation — quotes, contracts, CVs, reports. It takes seconds, it's free, and it removes an entire category of small, avoidable leaks.
