关于本工具

将多个 PDF 文件合并为一个。拖拽排序，无水印、无需注册。文件始终留在你的浏览器中。

隐私

一切都在你的浏览器中通过 pdf-lib 和 pdf.js 运行。你的文件绝不会接触服务器。打开开发者工具 → 网络，你会看到本页零流量。

提示

  • 使用 Chrome、Edge 或 Safari 以获得最佳性能。
  • 对于超大文件（100 页以上），关闭其他标签页以释放内存。
  • 需要批量处理？升级到专业版 — 不限文件数量，单个最大 500MB。

常见问题

我能不上传就合并 PDF 吗？

可以。合并完全在你的浏览器中通过 pdf-lib 运行 — 文件永远不会离开你的设备。打开开发者工具 → 网络，你会看到零上传流量。

有页数或文件数量限制吗？

没有硬性限制。超大任务（数百页）取决于你的设备内存；桌面浏览器处理最大批量效果最佳。

合并会改变质量吗？

不会。页面以无损方式复制到新文件 — 文本、图片和矢量图保持像素级一致。源文件内的书签会被保留。

合并前可以重新排序页面吗？

可以。拖拽文件重新排序整个文档，或先使用拆分功能删除特定页面，再合并结果。
