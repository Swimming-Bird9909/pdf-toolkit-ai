关于本工具

按页码范围、每 N 页或提取单页将 PDF 拆分为多个文件。免费、无需注册，文件始终留在你的浏览器中。

隐私

一切都在你的浏览器中通过 pdf-lib 和 pdf.js 运行。你的文件绝不会接触服务器。打开开发者工具 → 网络，你会看到本页零流量。

提示

  • 使用 Chrome、Edge 或 Safari 以获得最佳性能。
  • 对于超大文件（100 页以上），关闭其他标签页以释放内存。
  • 需要批量处理？升级到专业版 — 不限文件数量，单个最大 500MB。

如何把 PDF 拆分成单独的页面

  1. 打开 拆分 PDF，把文件拖入框内（或点击选择）。
  2. 选择模式：按页码范围（如 1-3, 5-12）、每 N 页拆分，或 提取单页（如 3, 7, 15）。
  3. 点击 处理 —— 拆分在你的浏览器里瞬间完成。
  4. 把生成的新 PDF 打包成 ZIP 下载，或逐页保存。

什么时候需要拆分 PDF？

  • 只分享文档的一部分 —— 发 50 页报告的第 5-10 页，其余内容不泄露。
  • 把大 PDF 拆成单页，方便打印、邮件发送或归档。
  • 从合并文件中提取单张发票、合同或某一页。
  • 重新排序页面 —— 先拆分，再用 合并 PDF 按新顺序重组。

不上传也能拆分 PDF

大多数在线拆分工具会把文件上传到服务器，我们不会。拆分完全在你的设备上用 pdf-lib 完成，合同、病历、财务文件绝不会离开你的电脑。打开开发者工具 → 网络，你会看到零上传流量。

常见问题

拆分机密 PDF 文件安全吗？

安全。拆分在你的浏览器本地完成。不上传任何内容，因此合同、医疗记录和财务报表永远不会离开你的设备。

拆分会降低质量吗？

不会。这是一项无损操作，将页面对象复制到新容器。文本和图片保持不变。

我可以按指定页码范围拆分吗？

可以 — 输入如 1-3、5-12、20-25 这样的范围，或提取单页（3、7、15），也可每 N 页拆分。

最大文件大小是多少？

实际约为 500MB（受浏览器内存限制）。更大的文件请分批拆分。
