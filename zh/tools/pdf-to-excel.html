关于此工具

本工具从 PDF 中提取文本，并整理为适合电子表格导入的结构。两种提取模式：纯文本（每个 PDF 行成为一行，整行文本放在一个单元格中 — 最适合文本内容，包括中文/CJK）和 区块分组（根据空间邻近度检测列结构 — 最适合真正的表格）。

工作原理

  • 上传 PDF — 一切都在你的浏览器中完成，无需上传。
  • 我们使用 pdf.js 提取带位置信息（x、y、宽度）的文本。
  • 在纯文本模式下，每个 PDF 行是一个 CSV 行，所有字符拼接到一个单元格中。智能间距：真实的间隔（例如英文单词之间）变为空格；CJK 字符（无间隔）保持连写。
  • 在区块模式下，我们将邻近的行在垂直方向分组，并按 x 坐标对齐，以近似表格结构。
  • 输出可在 Excel、Google Sheets、Numbers 及任何电子表格应用中打开。

局限性

  • 真实的表格检测（含合并单元格、边框）为尽力而为。对于复杂表格，请准备在 Excel 中手动整理。
  • 扫描件 PDF 需先运行 OCR 才能提取文本。
  • 如需像素级精确表格，请使用 PDF 转图片 + 付费 OCR 服务。

常见问题

我的表格会被完美保留吗？

老实说：不会。PDF 没有原生的表格结构 — 表格只是文本的可视化排版。我们的“区块分组”模式通过空间邻近度近似表格行，但包含合并单元格、多行单元格或特殊排版的复杂表格仍需要在 Excel 中整理。我们针对常见情况（财务报表、数据列表、简单网格）做了优化。

CSV 还是 TSV？

CSV（逗号分隔）是通用默认选项。如果你的数据包含很多逗号，请选择 TSV（制表符分隔）— TSV 无需转义逗号。

我能直接转换为 .xlsx 吗？

目前我们输出 CSV/TSV，Excel 可原生打开。原生 .xlsx 导出已在路线图中 — 现阶段只需将 .csv 重命名为 .xlsx，或在 Excel 中打开后另存为 .xlsx。
