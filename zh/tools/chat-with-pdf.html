关于本工具

用 AI 与任意 PDF 对话。上传文档，用自然语言提问，即可得到基于文档内容的答案 — 并附页码引用，方便核实。

工作原理

  • 上传 PDF — 文本使用 pdf.js 在本地提取，不上传、不走服务器。
  • 你的问题 + 相关文档片段会被发送给 AI 模型（GPT-4o-mini 或 Claude 3.5 Haiku）进行回答。
  • AI 被要求只根据文档回答，并附页码引用。
  • 点击任意引用即可跳转到文档中的对应页面。

隐私

  • 文本提取在你的浏览器本地完成。
  • 每个问题只把相关片段（而非整篇文档）发送给 AI。
  • 我们明确传递“禁止训练”标记。你的文档绝不会被用于模型训练。
  • 为获得最高隐私，可在设置中填入你自己的 API Key — 你的问题直接发往 OpenAI/Anthropic，不经过我们的服务器。

最适合

  • 阅读长篇合同、研究论文和报告
  • 从密集文档中提取特定事实
  • 无需通读全文即可快速找到需要的章节

常见问题

答案有多准确？

AI 被限制只能根据文档回答。对大多数事实性问题（X 是什么、Y 何时发生、Z 是谁），答案准确度很高。对主观问题（这份合同公平吗？），AI 会做总结但会标注为观点。

为什么有页数限制？

每个问题都会附带相关文档片段一起发送，我们对片段数量设限以保持响应快速并在模型上下文窗口内。免费版：25 页。专业版：200 页。对更长文档，请先用 AI 摘要工具获得精简版本。

可以使用自己的 API Key 吗？

可以。进入设置（右上角齿轮图标）粘贴你的 OpenAI 或 Anthropic API Key。之后你的问题将直接发往该服务商 — 我们的服务器从不会看到文档片段或你的问题。

支持扫描件 PDF 吗？

仅在该 PDF 已先经过 OCR 时支持。没有内嵌文字层的扫描件只是图片，AI 无可读取的文字。请先使用我们的
