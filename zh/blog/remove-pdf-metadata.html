PDF 到底悄悄存了什么

每个 PDF 都带一块元数据，绝大多数人从没看过。取决于它是怎么生成的，里面可能有：

  • 作者姓名——通常直接取自你的系统账户（比如 zhang.san 或 Administrator）
  • 创建程序——"Microsoft® Word 2019"、"Google Docs"、"Acrobat Pro"
  • 创建与修改时间——有时精确到秒
  • 编辑历史——文件被打开多久、保存过几次
  • 设备与系统信息
  • GPS 坐标——某些手机扫描 App 生成的 PDF 会带上
  • 公司 / 模板名称——所用模板的内部命名

这些在你打开文档时全都看不见，只有别人特意去查才会暴露。

实际会出什么问题

几个真实场景下元数据惹的麻烦：

  • 发给客户的报价单，暴露了内部模板名和员工的系统账号。
  • 求职者的简历显示最后修改时间是凌晨 1:40——而且最初是用另一家公司的模板创建的。
  • 一份扫描合同里嵌了扫描地点的 GPS 坐标。
  • 外发的草稿仍带着发件人以为已经清掉的修订痕迹。

这些都算不上灾难，但全都是十秒钟就能避免的。

怎么查看里面有什么

最快：用浏览器打开 PDF，按 Ctrl/Cmd + D，看文档属性面板。

Windows：右键文件 → 属性 → 详细信息标签页。

macOS：用预览打开 → 工具 → 显示检查器 → 信息（ⓘ）标签页。

怎么清除（免费，不上传）

打开 PDF 元数据清除工具，拖入文件，点击清理。它会重写文档，去掉作者字段、时间戳、软件标记和隐藏的 XMP 块，然后给你一个全新的下载文件。

由于全程在浏览器里运行，文件不会离开你的电脑。这正是关键——你要清理它是因为它敏感，那么把它上传到某个陌生服务器就本末倒置了。

其他方法

Acrobat Pro：工具 → 密文 → 删除隐藏信息。功能强，但要付费，且默认上传云端。

Microsoft Word：文件 → 信息 → 检查问题 → 检查文档 → 全部删除。对 Word 能重新打开的 PDF 效果不错。

打印成 PDF：macOS 上用预览打开后 打印 → 存储为 PDF。通常能去掉元数据，但也可能把文字栅格化，导致无法搜索。

元数据清除做不到什么

要清楚边界，否则会产生虚假的安全感：

  • 它不会去掉可见水印——那要用 去水印工具。
  • 它不会删除批注、高亮和便签。
  • 它不会"白底白字"的隐藏文字层。
  • 它不会动已经印在页面上的内容——看得见的东西依然看得见。

如果你需要把页面内容本身涂黑，请用正规的密文工具，而不是元数据清理工具。

养成习惯

最稳妥的流程其实很无聊：凡是离开公司的文件——报价单、合同、简历、报告——都先清一遍元数据。几秒钟、免费，却堵掉了一整类本可避免的小泄漏。
