如何把 PDF 表格转成 Excel
——一个格子都不用重录

PDF 并不知道什么是行、什么是列，所以从里面复制表格往往会毁掉整个版式。这里有三种把数据弄进表格软件的方法，其中一种不会上传你的文件。

为什么 PDF 里的表格这么难用

PDF 的设计目标是"还原一页印刷品"，而不是保存数据网格。它只记录每个字符落在页面的哪个位置，并不知道"第 14 行 C 列"是什么。所以你从 PDF 里复制表格时，经常得到一整列挤在一起、对齐全乱的数字。

好的转换工具必须重建整个网格：先识别表格线，再把文字聚合成单元格，最后判断哪些块属于同一行。源文件越规整，结果越干净。

方法一：浏览器本地转换（免费，不上传）

打开 PDF 转 Excel 工具，拖入文件，点击转换。它会读取文字块、对齐到行列网格，然后给你 .xlsx 和 .csv 两种结果，你按表格软件的喜好选一个。

适用场景：银行流水、发票、报价单、问卷导出，以及任何你本来要手工重录的表格。

因为全程在浏览器里跑，财务文件不会经过任何第三方服务器。这一点比很多人想的重要——一份银行流水里有你的地址、账号和消费记录。

方法二：Adobe Acrobat Pro（付费，走云端）

Acrobat Pro → 导出 PDF → 电子表格 → Microsoft Excel 工作簿。它对复杂版式的识别最准，还允许你在导出前手工修正表格边框。缺点是每月 22.99 美元，而且除非在设置里关掉，文件会上传到 Adobe 云端处理。

方法三：Google Drive / 表格（免费，但要上传）

把 PDF 上传到 Drive，右键 → 打开方式 → Google 表格，Google 会生成一个含提取文字的新表格。免费且快，但跨页表格经常错位，而且文件会存在 Google 服务器上。

临时处理一份价目表没问题，机密文件就别这么干了。

常见问题与解决办法

"合并单元格塌成一格"

合并表头是最难的情况。如果导出的表头全挤在一列，改用 .csv 导出，再在表格软件里用固定分隔符分列。慢一点，但结果可预期。

"数字变成了文本"

货币符号和千分位分隔符经常导致这个问题。Excel 里选中该列 → 数据 → 分列 → 完成。Google 表格用 =VALUE(SUBSTITUTE(A1,",",""))。另外注意欧式的小数逗号——先把 , 换成 .。

"跨两页的表格被拆错了"

那就一页一页提取。先用 拆分 PDF 在表格边界处切开，分别转换，再把结果拼起来。这比指望工具猜对可靠得多。

"什么都提取不出来"

那这份 PDF 很可能是扫描件——是表格的照片，不是真正的文字。先跑一遍 PDF OCR 加上文字层，再转换。

隐私

我们的转换工具完全在你的浏览器里运行。文件在本地解析、表格在本地生成、下载也在本地完成——不上传、不用注册、服务端不留副本。如果表格里有客户姓名、工资或银行账号，就该用这个版本。
