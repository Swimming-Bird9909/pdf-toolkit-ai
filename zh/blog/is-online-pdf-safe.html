人人都会问的问题

“我需要合并两份 PDF——用在线工具安全吗？”这是个合理的问题。你正准备把一份文档交给一个你从没听说过的网站。也许它是一份合同。也许是医疗记录。也许是写着你电话号码和家庭住址的简历。

答案完全取决于工具如何处理你的文件。而这里有两种根本不同的模式。

上传 PDF 时发生了什么

当你使用一个典型的在线 PDF 工具——那种写着“上传你的文件”的——实际发生的是：

  1. 你的 PDF 通过互联网传送到一个你无法控制的服务器。
  2. 服务器上的软件处理它（合并、压缩、转换等）。
  3. 结果发回给你。
  4. 服务器可能删除你的文件。也可能不会。

问题出在第 4 步。你在相信供应商“文件已删除”的口头承诺。但服务器日志、备份、CDN 缓存和错误上报系统都可能在供应商毫无察觉的情况下保留了你文件的副本。

在线 PDF 工具的 3 个风险等级

高风险：没有隐私政策的免费工具

这些网站没有隐私政策、没有公司名称、没有地址。它们铺满广告。它们存在的目的是收割文件——要么用于数据挖掘，要么用于训练 AI 模型，或者仅仅因为运营者不懂如何保护服务器。

危险信号：没有“关于”页面、没有隐私政策、广告泛滥、文件大小限制像是故意把人逼向付费档、不提数据存储在何处。

中等风险：Freemium SaaS（Smallpdf、ILovePDF、SodaPDF）

这些都是有隐私政策和数据留存规则的合法公司。它们在服务器端处理你的文件，然后声称会在一段时间后（通常 1–2 小时）删除。对于非敏感文档，这通常可以接受。

但“1 小时后删除”也有前提：

  • 备份可能把文件保留数天甚至数周。
  • 服务器日志可能包含文件元数据。
  • 如果公司被攻破，你的文件可能在删除前就已泄露。
  • 某些“免费”档会分析文件内容用于广告或 AI 训练。

结论：公开文档没问题。任何机密文件都有风险。

零风险：客户端工具（比如我们）

客户端工具完全在你的浏览器中处理你的文件。文件永远不会离开你的设备。没有上传、没有服务器处理、没有留存策略——因为根本没有需要留存的东西。

这正是 PDF Toolkit AI 的做法。每一款工具——压缩、合并、拆分、OCR、AI 摘要——都使用 pdf-lib、pdf.js 和 Tesseract.js 等 JavaScript 库在本地运行。

如何验证一款工具真的是客户端处理

不要只听网站的口头宣传。你 30 秒就能验证：

测试一：网络面板

  1. 在浏览器中打开该工具。
  2. 按 F12 打开开发者工具。
  3. 切换到 网络 面板。
  4. 上传一个 PDF。
  5. 观察网络流量。

如果你看到一条大型 POST 请求，带着你的文件发往某个服务器——那它就不是客户端处理。如果唯一的网络流量只是页面初次加载和 CDN 资源（CSS/JS），那工具就在本地处理。

测试二：离线测试

加载工具，然后断开网络（关掉 Wi-Fi）。试着处理一个 PDF。如果能用，说明工具是客户端处理。如果因网络错误而失败，说明它依赖服务器。

测试三：阅读源码

客户端工具会在你的浏览器中加载全部处理代码。你可以阅读那些 JavaScript。在源码中找 pdf-lib、pdfjs-dist、tesseract.js 这类库——这些都是客户端 PDF 库。

真实世界的恐怖故事

以下情景基于有记录的真实事件整理而成：

  • 泄露的简历：一位求职者用免费 PDF 转换器整理简历。该转换器的服务器配置错误，导致上传的文件通过公开 URL 被暴露。那份带完整联系方式的简历被搜索引擎收录。
  • 医疗记录：一位患者用在线工具把体检结果转成 PDF。该工具的隐私政策允许“为改进服务而分析文件内容”。敏感健康数据被第三方分析服务处理。
  • 机密合同：一家律所的实习生用免费 PDF 合并器合并合同草稿。合并后的文件被临时存放在一个共享云服务器上，因权限漏洞可被其他用户访问。

试金石

把任何 PDF 上传到在线工具之前，先问自己：

“如果这份文件印在纸上，我会把它交给互联网上的一个陌生人吗？”

如果答案是否定的——而对大多数工作文档来说本该如此——那就改用客户端工具。

常见问题

HTTPS 难道不能在上传时保护我的文件吗？
HTTPS 加密传输中的数据（浏览器与服务器之间）。它能防止窃听。但一旦你的文件到达服务器，HTTPS 就提供零保护。无论有没有 HTTPS，服务器都可以存储、分析或泄露你的文件。

那“1 小时后删除文件”呢？
这是承诺，不是保证。备份、日志和缓存层都可能把副本保留到声明删除时间之后。而且“删除”可能只是软删除（在界面上隐藏但仍留在磁盘上），而非安全擦除。

客户端工具会更慢吗？
对小于 100MB 的文件，差别可以忽略不计——往往更快，因为没有上传/下载的来回往返。对超大文件（500MB+），拥有强力 CPU 的服务器可能更快，但你是在用速度换取隐私。

网站能通过 JavaScript 偷走我的文件吗？
恶意网站理论上可以在你授权的情况下（例如通过文件选择器）读取你设备上的文件。但声誉良好的客户端工具只会访问你明确选择的文件，在内存中处理，且从不传输。如果不确定，随时查看网络面板。

要点

并非所有在线 PDF 工具都同等安全。关键区别不在于“免费 vs 付费”——而在于服务器端 vs 客户端。服务器端工具要求你把自己的文件托付给第三方。客户端工具则不需要。

PDF Toolkit AI 上的每一款工具都是客户端处理。你的文件永远不会离开你的浏览器。这不是营销口号——用你浏览器的开发者工具，30 秒就能验证。
