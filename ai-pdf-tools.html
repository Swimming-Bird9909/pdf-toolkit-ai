Frequently asked questions

Common questions about ai pdf tools.

Which AI model powers the summarizer?

We use a mix of GPT-4o-mini and Claude 3.5 Sonnet, picked per-task. Short documents (< 50 pages) can also run on-device for zero-upload privacy.

Is my PDF used to train AI models?

Never. We send PDFs over HTTPS only when cloud processing is required, and pass the "do not train" flag explicitly. Set your own API key in settings to use your own account.

How accurate is Chat With PDF?

Answers are grounded in the document content with page citations. For ambiguous questions, the AI says "I don't know" rather than guessing.
